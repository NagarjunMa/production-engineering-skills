Add adjust_many(stock, adjustments) to the existing stock module. adjustments is an ordered list of (sku, integer_delta) pairs. Apply the same validation and error types as adjust_stock to each pair, in order, using tentative quantities. Repeated products are allowed and must be processed sequentially; an intermediate negative quantity is invalid even if a later adjustment would restore it. On success update the supplied stock dictionary and return a dictionary of final quantities for the products touched. On any unknown product or underflow, leave the entire supplied stock dictionary unchanged, even when earlier pairs were valid. An empty list returns an empty dictionary without mutation. Preserve adjust_stock behavior. Do not add dependencies, a UI, persistence, or deployment. Complete the implementation and meaningful tests.
