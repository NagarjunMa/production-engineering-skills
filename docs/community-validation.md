# Community validation record

Use this record for tests performed by different developers, projects, operating systems, Codex versions, and other supported hosts. Share no private source, credentials, customer data, environment dumps, or personal filesystem paths.

One successful run establishes only that environment and task. Keep failures and blocked runs; do not calculate a quality or token-savings claim without a matched design, repeated trials, and actual measurements.
